# Repository and notes vault are separate

- Status: accepted
- Owner: User
- Date: 2026-10-27

## Context

Private study notes (Polish, Obsidian) and project code have different audiences.

## Decision

The repository is English and code-only. Notes, canvases and theory live in the separate `music-map-notes` vault.

## Alternatives and rationale

A shared vault would put editor state and Polish notes in a public repository.

## Participants and acceptance evidence

User instruction on 2026-10-26.

## Consequences

No Obsidian files or wikilinks in the repository.
